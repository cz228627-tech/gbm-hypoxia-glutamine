# gbm-hypoxia-glutamine
hypoxia and glutamine metabolism in glioblastoma
This repository contains the Python analysis scripts and independent R statistical workflows for the study.

The code, data-source notes, software citation metadata, and run instructions are in [`GBM_hypoxia_glutamine-GitHub/`](GBM_hypoxia_glutamine-GitHub/). Start with its [README](GBM_hypoxia_glutamine-GitHub/README.md) and [run guide](GBM_hypoxia_glutamine-GitHub/RUN_GUIDE.md).

The repository does not distribute raw expression data or patient-level data. See the data-source notes for public accessions.

A version-specific Zenodo DOI will be added after the first release is archived.
